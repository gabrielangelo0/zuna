# Créditos dos assets

Todos os modelos 3D usados para gerar os sprites são **CC0 1.0 (domínio público)**: uso comercial liberado, sem obrigação de atribuição. Mesmo assim, registramos a origem de cada pacote.

Os arquivos originais ficam em `assets/source/` (fora do git). Para baixá-los:

```bash
npm run assets:download
```
